# ⚡ 번개냥타자 (Lightning Cat Typing)

번개냥과 함께하는 한글 타자 연습 게임이에요. 하늘에서 번개처럼 떨어지는 단어를 입력해서 잡는 방식으로, 초등학생 타자 연습용으로 만들었어요.

## 게임 방법

1. `index.html` 파일을 웹 브라우저로 열어요.
2. 난이도(쉬움/보통/어려움)를 선택해요.
3. 화면 위에서 떨어지는 단어를 입력창에 그대로 입력하면 번쩍! 하고 사라지며 점수를 얻어요.
4. 단어가 바닥에 닿기 전에 못 잡으면 목숨(❤️)을 하나 잃어요. 목숨을 모두 잃으면 게임 종료!
5. 게임이 끝나면 이름을 입력해서 순위표(명예의 전당)에 기록을 남길 수 있어요. (기록은 사용하는 브라우저에 저장돼요)

## 파일 구성

- `index.html` — 게임 본체 (HTML/CSS/JS 한 파일)
- `번개냥.png` — 캐릭터 이미지 (게임 화면 상단 배지)
- `번개냥전체.png` — 캐릭터 배경 이미지 (시작 화면 배경, 동영상 대체용)
- `번개냥.mp4` — 시작 화면 인트로 영상

## GitHub Pages로 온라인 공개하기 (선택)

이 저장소를 웹사이트처럼 누구나 접속할 수 있게 하려면:

1. GitHub 저장소 페이지 상단의 **Settings** 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. "Build and deployment" 항목에서 Source를 **Deploy from a branch**로 설정
4. Branch를 **main**, 폴더를 **/(root)**로 선택 후 **Save**
5. 잠시 후 `https://jessie1895-cloud.github.io/lightningcat-typing/` 주소로 접속하면 게임을 바로 플레이할 수 있어요.
